# Zoom Auto

Небольшое приложение для Ubuntu: в нужное время само открывает Zoom-ссылку пары.

## Возможности
- расписание по дням недели (Пн-Вс), по умолчанию Пн-Пт
- автозапуск при входе в систему, работает свёрнутым в фоне
- автоматическая копия ссылок и текстовый список `links.txt`

## Установка
    git clone https://github.com/rus1amturdaliev/zoom-auto.git
    cd zoom-auto
    bash install.sh

## Запуск
    python3 study_timer.py

## Где хранятся данные
Пары и ссылки лежат в `~/.config/study-timer/`, а не в репозитории.
